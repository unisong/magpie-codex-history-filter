# v0.2.0 · Magpie Codex 合并工作台

将历史过滤、可选模型指纹检测和模型暂停保护合并为一个 Magpie 插件，沿用本仓库原包名，正式发布记录为 **v0.1.0 → v0.2.0**，支持 GitHub 和社区包名安装。

合并版已提交 [Magpie 社区市场更新 PR #168](https://github.com/magpie-community/plugins/pull/168)，官方自动检查通过，等待维护者审核合并。合并并完成分发前，**GitHub 发版不代表市场已更新**。

- 原生「Codex Workbench · 历史过滤」页面直接按供应商设置开关；只用过滤无需登录或打开独立工作台。未配置供应商默认直通，原历史算法不变。
- 可选本机工作台提供 ModelTrace 指纹、手动检测、定期观测、异常暂停、分页记录及诊断。没有监测目标时不取样，检测故障不阻断历史过滤。
- 与 CC Switch 工作台统一四个分区、暖灰/铜色配色和单图标明暗切换。自动展示最近实际 Codex 路由，其次采用检测记录，缺少记录才手动选择；当前页内调整监测，无需二级添加页面。
- 补齐全新演示截图、安装迁移、结果边界、用量预算和维护说明，以及可选只读诊断工具。

## 安装与迁移

```sh
magpie plugin add github:unisong/magpie-codex-history-filter#v0.2.0
```

也可下载 ZIP 解压并添加本地目录。已在 Magpie 0.1.1265 验证，工作台使用宿主自带 Bun。Windows 打开控制台可双击包内 `Open.bat`，也可从 Magpie 的本机控制台入口打开，无需账号登录。

先私下备份原插件 Options 与 `~/.config/magpie-model-workbench/`。将供应商规则及其他 Options 保留到合并版，只启用一个副本。原目标、记录、预算与暂停状态沿用；有定期目标时将继续调度，关闭页面不会停用它们。不改动 Codex 的 `base_url`。

## 验证与限制

离线单元测试、页面交互与隔离 Magpie 模拟上游验证覆盖过滤保留、独立模型暂停、官方路由读取、配置冲突及重载。截图使用虚构数据，测试不调用真实供应商。

指纹是有限参考库内的统计结果，不能认证模型身份或保证推理质量。暂停仅拦截后续请求，不能撤回输出。完整工作台在本机浏览器打开，原生页面保留过滤设置；详细限制见 README。
